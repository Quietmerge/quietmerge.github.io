What the Service does

QuietMerge reviews Terraform and OpenTofu dependency-update pull requests on the repositories you install it on. It verifies them using a terraform plan that runs in your own CI, posts a plain-English verdict, and — where you have opted in — automatically merges pull requests that are provably no-ops.
